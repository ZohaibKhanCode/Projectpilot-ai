# Project Idea

**ProjectPilot AI** is an AI-powered project discovery and planning platform designed to help students, beginner developers, and software enthusiasts transform their ideas into structured, real-world projects.

Choosing the right project is one of the biggest challenges in software development. Many learners know the technologies they want to learn but struggle with:

* Finding meaningful project ideas
* Selecting the right technology stack
* Understanding project complexity
* Creating a development roadmap
* Building portfolio-worthy applications

ProjectPilot AI solves this challenge by acting as an **AI software project mentor** that generates personalized project ideas based on the user's skills, interests, and experience level.

Instead of providing random project suggestions, it creates a complete development blueprint that guides users from idea → implementation.

# ⚙️ How to Run the Project

Follow these steps to run ProjectPilot AI on your local machine.

## 1. Clone the Repository

```bash
git clone [https://github.com/ZohaibKhanCode/Projectpilot-ai.git]
```

## 2. Navigate to the Project Directory

```bash
cd ProjectPilot-AI
```

## 3. Install Dependencies

```bash
npm install
```

## 4. Configure Environment Variables

Create a `.env` file in the project root and add your Groq API key:

```env
VITE_GROQ_API_KEY=your_groq_api_key_here
```

> You can get a Groq API key by creating an account on the Groq developer platform.

## 5. Start the Development Server

```bash
npm run dev
```

## 6. Open the Application

Once the server starts, open your browser and visit:

```
http://localhost:5173
```

The application is now ready to use.
